# Historical implementation stages

These files record the staged migration that produced the final ASE 1.0 architecture. They are historical implementation records, not competing sources of truth for current architecture/configuration.

1. `BASELINE_STAGE1.md` — reproducible baseline and public contract locks
2. `STAGE2_CANONICAL_ENGINE.md` — canonical model/parser engine
3. `STAGE3_DISCOVERY_ENGINE.md` — adaptive discovery/source intelligence
4. `STAGE4_STATIC_IP_HUNTER.md` — DNS-derived direct-IP discovery
5. `STAGE5_VERIFICATION_ENGINE.md` — verification engine v2
6. `STAGE6_SMART_SCHEDULER.md` — persistent candidate scheduler
7. `STAGE7_MULTI_CLIENT_ENGINE.md` — multi-client/core runtime
8. `STAGE8_OPERATOR_PROBE_SYSTEM.md` — authenticated physical operator probes
9. `STAGE9_SCORING_ENGINE.md` — multidimensional contextual scoring
10. `STAGE10_FEED_ENGINE.md` — score-aware final feed membership
11. `STAGE11_PRODUCTION_HARDENING.md` — durable state/release hardening

Current documentation lives at the top of `docs/` and in the repository `README.md`.
